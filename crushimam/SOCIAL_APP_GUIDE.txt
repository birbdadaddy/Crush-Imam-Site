SOCIAL APP - INSTAGRAM-STYLE SOCIAL NETWORK FOR CRUSHIMAM
=========================================================

A complete Instagram-style social networking app built with Django and Channels for the CrushImam community site.

## FEATURES IMPLEMENTED

### 1. User Profiles ✓
- Public/Private profile modes
- Bio, profile picture, cover photo, website, location
- Verified badges
- Follower/Following counts
- Profile editing for authenticated users

### 2. Posts & Feed ✓
- Text-only, image, video, or multi-media carousel posts
- Anonymous posting option (random username/avatar)
- Like/Unlike functionality
- Comment with nested replies
- Save/Bookmark posts
- Post creation, editing, deletion
- Home feed: posts from followed users
- Explore/Discover feed: all public posts
- Infinite scroll with pagination

### 3. Stories ✓
- 24-hour temporary content (auto-expires)
- Image and video support
- Story views tracking
- Stories bar on feed showing followed users' active stories
- Create story view with preview

### 4. Interactions ✓
- Like/Unlike posts and comments
- Nested comment replies
- Comment deletion
- Save/Bookmark posts
- Share post links
- Report inappropriate content with reasons

### 5. Direct Messaging (DMs) ✓
- Private messaging between users
- Text message support
- Message read receipts
- Conversation tracking
- Real-time messaging with WebSockets
- Typing indicators
- User online/offline status

### 6. Notifications ✓
- Real-time notifications for likes, comments, follows, DMs
- Notification types: like, comment, follow, message, mention, story_view
- Mark as read functionality
- Real-time delivery via WebSockets

### 7. Follow System ✓
- Public profile: direct follow
- Private profile: follow requests (pending/accepted/rejected)
- Unfollow functionality
- Follow counts

### 8. Privacy & Blocking ✓
- Public/Private profile toggle
- Block users (mutual follow removed)
- Unblock functionality
- Mute notifications from users
- View blocked users list

### 9. Search ✓
- Search users by username/name
- Search posts by caption
- Search hashtags
- Filtered results

## MODELS (18 Total)

### Core Models
- **UserProfile**: Extended user profile with bio, pictures, privacy settings
- **Post**: User posts with UUID, anonymous option, archive flag
- **PostMedia**: Carousel support - multiple images/videos per post
- **Story**: 24-hour stories with auto-expiry, thumbnail support
- **StoryView**: Track story viewers

### Social Relationships
- **Follow**: User follow relationships (indexed)
- **FollowRequest**: Private account follow requests
- **BlockedUser**: Block relationships
- **MutedUser**: Mute notifications without unfollowing

### Interactions
- **Like**: Post likes (unique per user/post)
- **Comment**: Nested comment replies, anonymous support
- **CommentLike**: Like comments
- **Bookmark**: Save/bookmark posts

### Messaging
- **DirectMessage**: DM with read receipts, multiple types (text/image/voice)
- **Conversation**: Track active DM conversations

### Metadata
- **Notification**: Real-time notification tracking
- **ContentReport**: Report inappropriate content with reasons
- **Hashtag**: Track popular hashtags and usage count

## VIEWS (30+)

### Feed Views
- `FeedView`: Home feed (authenticated users only)
- `explore_feed()`: Discover/explore all public posts

### Post Views
- `CreatePostView`: Create new post with media handling
- `PostDetailView`: Single post with comments and interactions
- `UpdatePostView`: Edit post caption
- `DeletePostView`: Delete post
- `like_post()`: Like/unlike post (AJAX + form submission)
- `add_comment()`: Add comment to post
- `delete_comment()`: Delete comment
- `bookmark_post()`: Save/bookmark post

### Profile Views
- `user_profile()`: View user profile with privacy checks
- `edit_profile()`: Edit own profile
- `follow_user()`: Follow user (requests if private)
- `unfollow_user()`: Unfollow user
- `block_user()`: Block user
- `unblock_user()`: Unblock user

### Story Views
- `stories_view()`: List active stories from followed users
- `story_detail()`: View single story with tracking
- `CreateStoryView`: Create new story

### Messaging Views
- `messages_view()`: List all conversations
- `conversation_detail()`: View DM thread
- `send_message()`: Send direct message
- `start_conversation()`: Start new conversation with user

### Other Views
- `notifications_view()`: View all notifications
- `report_content()`: Report post/comment/message
- `search_view()`: Search users, posts, hashtags

## FORMS (10+)

- `UserProfileForm`: Edit profile
- `PostCreationForm`: Create post with privacy options
- `PostMediaForm`: Multiple media upload
- `CommentForm`: Comment with anonymous option
- `DirectMessageForm`: DM with message type
- `StoryCreationForm`: Create story
- `ContentReportForm`: Report content
- `SearchForm`: Search interface
- `BlockUserForm`: Confirm block action

## SIGNALS (Auto-Actions)

### Profile Signals
- Auto-create UserProfile when new User is created
- Auto-save UserProfile when User is saved

### Notification Signals
- Create notification on Post like
- Create notification on Comment
- Create notification on Reply to comment
- Create notification on Follow
- Create notification on DM
- Create notification on Story view
- Delete related notifications when content is unliked

### Anonymous Signals
- Auto-generate random name for anonymous posts
- Auto-generate random name for anonymous comments

### Story Signals
- Auto-set story expiry time to created_at + 24 hours

## WEBSOCKET CONSUMERS (Real-Time)

### NotificationConsumer
- Endpoint: `ws/notifications/`
- Sends real-time notifications to users
- Groups: `notifications_{user_id}`

### ChatConsumer
- Endpoint: `ws/chat/{conversation_id}/`
- Real-time messaging with typing indicators
- User online/offline status
- Message read receipts
- Groups: `chat_{conversation_id}`

### FeedConsumer
- Endpoint: `ws/feed/`
- Real-time feed updates
- New posts, likes, comments
- Groups: `feed_{user_id}`

## USAGE GUIDE

### User Workflow

1. **Create Profile**
   - Auto-created on user registration
   - User can edit via `/social/profile/edit/`
   - Set bio, picture, privacy level

2. **Make Posts**
   - Navigate to `/social/post/create/`
   - Add caption and media
   - Choose anonymous mode if desired
   - Post publicly or as anonymous

3. **Discover Content**
   - Home feed: posts from followed users
   - Explore page: all public posts
   - Search: find users or posts

4. **Interact**
   - Like posts (real-time count update)
   - Comment and reply
   - Save posts for later
   - Share post links

5. **Follow & Connect**
   - Follow public profiles directly
   - Send follow requests to private profiles
   - Block unwanted users
   - Mute notifications from specific users

6. **Direct Message**
   - Start conversation from profile
   - Send text messages (real-time)
   - See typing indicators
   - Check read receipts

7. **Stories**
   - Upload 24-hour stories
   - View stories from followed users
   - Disappear automatically after 24h
